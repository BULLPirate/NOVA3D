Игра **Knight Bandits** — отдельный проект, не часть исходников движка.

Создаётся и запускается так:

```bash
cd ~/Desktop/NOVA3D && ./Tools/run.sh knight
```

Папка: `~/Documents/NOVA3D/Projects/KnightBandits`

Управление: мышь — обзор, WASD, Shift — бег, F/ЛКМ — удар, R — встать, F8/F9 — быстрый сейв.

В проекте лежат модели `Assets/Characters/knight_armed.obj` и `bandit.obj`, не кубы из редактора.
