# NOVA3D MVP

Движок стартует **пустым**. Игра — отдельный проект на диске.

```bash
cd ~/Desktop/NOVA3D && ./Tools/run.sh editor
```

Цикл редактора: Проекты → сцена → куб/сфера/модель → Move/Rotate/Scale → камера/свет в инспекторе → Ctrl+S → F5 Play / F6 пауза / Esc стоп → Cmd+Shift+G standalone.

Шаблоны: пустой, от третьего лица, Knight Bandits.

```bash
./Tools/run.sh knight
```

Игра: мышь, WASD, удар F/ЛКМ, пять волн, F8/F9 сейв, R после победы — заново.
